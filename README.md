# Game Job Test

게임회사 취업 준비생이 자신의 업무 성향을 바탕으로 게임 개발 직무를 탐색할 수 있는 웹 테스트입니다.

## MVP

- 30개 4지선다 질문
- 6개 성향축: Logic / System / Visual / Experience / Analysis / Communication
- 50개 게임 업계 직무 프로필
- 성향 유사도 85% + 직접 직무 보너스 15%
- 추천 직무 Top 5
- 모바일 우선 UI

## Stack

- React
- TypeScript
- Vite
- CSS

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

> 이 테스트는 심리검사나 채용 적성검사가 아니라 직무 탐색을 위한 콘텐츠형 추천 도구입니다.
